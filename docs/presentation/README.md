# The presentation

[`index.html`](index.html) is the talk: 25 slides in one page, with the fonts inside, so it works offline. GitHub shows
its source, so download it (or clone the repository) and open it in Chrome, Edge or Firefox.

Slides 7, 9, 11, 13, 15, 17, 19, 20 and 21 animate the stage they describe: the question it answers, what happens, then
its exit criterion. Each animation starts with its slide, plays once, then holds the finished diagram. The slide after
most stages shows the idea behind it.

| Key | Does |
| --- | --- |
| → Space PageDown, or a click | next slide |
| ← PageUp | previous slide |
| a number, then Enter | go to that slide |
| Home / End | first / last slide |
| R | replay the animation |
| P | pause or resume the animation |
| F | full screen |
| B or . | black screen |
| ? | the list of keys |
